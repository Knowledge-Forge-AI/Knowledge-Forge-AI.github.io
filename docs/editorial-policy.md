# Release journal

The owner requested posts dated to the original release or milestone. New
entries use that date, with an actual modification date recorded separately.
Versioned release dates come from GitHub's public published_at records; signed
repository milestones use the successful production deployment date. The CLOE
direction is the steward's 11 November 2026 project milestone.

The archive covers all 47 versioned public GitHub releases found across APGR,
the six Theme Forge products and the three DINAS preview repositories on
11 November 2026. Related Theme Forge products released on the same UTC day
share an organizational post. The original APG 0.3.0 article and URL remain
unchanged. `src/data/release-records.json` maps each release to its article.

Each entry links primary records and preserves release-era target, distribution
and preview limits. An artifact on GitHub does not establish publication on
every registry. A source preview is not host installation or activation. Tagged
APGR 0.13 notes retain candidate-era status language; the actual published
release/attestations establish release identity.

RepoMap has no versioned GitHub release in this inventory. Common Lore Index
(CLOE) is its in-progress rebrand, not a new package name, CLI or released
version. The connection from DINAS to RepoMap is the project steward's origin
account; public DINAS source and RepoMap documentation supply the technical
context. Do not promote private operational journals into public posts.

Future updates should verify the release record, retain old article identities
and link the product's own installation and licensing documentation. Never
invent publication dates, registry completion or platform qualification.
