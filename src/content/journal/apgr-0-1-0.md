Agentic Praxis Grimoire begins with six jobs that keep returning in software work: assigning bounded work, designing consequential changes, planning, implementing with tests, debugging, and reviewing the result. Version 0.1.0 gives each job a focused skill with a reason to use it, a reason not to, and a point at which it should stop.

The aim is useful judgment rather than a universal ceremony. A skill contributes a procedure; the project and its owner still supply the authority, constraints and definition of success. The initial release also includes discovery and adoption tooling that respects existing repository content.

This is a public foundation for bounded experimentation. Its bootstrap scenarios, review and early dogfooding do not establish automatic skill selection or a production warranty.
