APGR 0.11.0 publishes the qualified toolkit through its release and package ecosystem, adding the Knowledge Forge AI Homebrew tap as a distribution channel. The supported target set is Apple Silicon, Linux AMD64 and Linux ARM64; Intel macOS is explicitly outside it.

The release retains forty-five skills, with fourteen stable and thirty-one provisional leaves. It also preserves the recorded CSS and JavaScript qualification debt. More ways to install a tool do not change the maturity of its guidance.

The release notes distinguish native execution evidence from formula syntax, checksums and package metadata. That distinction matters when choosing an installation route: a correct formula and a correct binary are related proofs, not interchangeable ones.
