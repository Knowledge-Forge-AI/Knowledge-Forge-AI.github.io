The single-phase execution runtime transfers from Agent-Central into APGR. Request V2 execution, persistence, rerouting, result repair and explicit Git finalization now sit beside the public Go domain packages and JACA XO integration surface.

This is an ownership change as much as a feature release: the toolkit can carry a phase from a structured request to a durable result without requiring a separate checkout to own the runtime. The forty-five-skill corpus has no maturity promotion in this version.

The release binds its package archives to qualified source and preserves their bytes through publication. Its notes also keep registry completion separate from attaching files to GitHub; one successful channel is not proof that every other channel has finished.
