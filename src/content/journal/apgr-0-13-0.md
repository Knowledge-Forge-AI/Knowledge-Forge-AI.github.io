APGR 0.13.0 carries an independently usable single-phase dispatcher, a defined operator-home layout and review-stage worktree mutation controls. It also adds optional RTK integration, operational observations and a first-party Nix distribution surface.

The context-management experiment is deliberately opt-in. Static transport remains the default; the adaptive pilot has a documented scope and does not claim measured provider-token savings. The catalog reaches forty-six skills without a maturity promotion.

The tagged feature notes retain candidate-preparation status text. The published GitHub release and its attestations establish the actual release identity; those earlier notes should not be read as a final all-channel availability report. This remains an early pilot, with target and installation details owned by the distribution documentation.
