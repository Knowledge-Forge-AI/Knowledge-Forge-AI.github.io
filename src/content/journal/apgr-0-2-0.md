Version 0.2.0 promotes the six original process skills to stable within their documented boundaries. That decision follows recorded use, non-trigger and stop cases, regression checks and fresh review; it is not a claim that every task should invoke every skill.

The other substantial change is delivery. A deterministic public-release builder checks the projected source and append-only lineage, while managed lifecycle operations make adoption, verification and rollback explicit. The release process also detects the omitted-wrapper problem present in the first public version.

The result is a more dependable way to consume the same small process core. Existing releases retain their own history and contracts rather than being rewritten to resemble the newest catalog.
