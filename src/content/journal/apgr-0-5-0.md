Earlier public releases used the APG abbreviation; the apgr command-line name arrives with this release. The new apgr Python CLI gives the grimoire a concrete operational interface. User and project configuration have separate homes, and outbox, report and numbered-response contracts make the boundaries between a request and its recorded result easier to follow.

CSS, Markdown, JavaScript, TypeScript and Node.js profile work brings the public library to thirty-three skills. These profiles help when language-specific judgment matters; their presence does not impose a compulsory stack-wide procedure.

Maturity remains specific to each skill. The release retains the accepted CSS and JavaScript qualification debt and does not include a Nix deployment adapter. Those limits remain part of the published version, rather than disappearing behind the new CLI.
