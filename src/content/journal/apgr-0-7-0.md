APGR becomes easier to embed in another system. Public Go packages expose schemas, reports, skill bundles, environment snapshots and structural hotspot analysis, while the Go-backed command line keeps compatible Python adapters.

The release defines native Python wheels, an npm launcher and platform packages for Apple Silicon, Linux AMD64 and Linux ARM64. The npm route selects a packaged executable rather than downloading a runtime substitute or falling back to JavaScript semantics.

The thirty-nine-skill corpus is unchanged: fourteen stable and twenty-five provisional leaves. Packaging and embedding expand the ways to use the toolkit; they do not deploy it to a host or decide an orchestrator's policy.
