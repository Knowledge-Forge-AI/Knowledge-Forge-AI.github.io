The first DINAS Browser UX preview makes browser baseline-policy contributions, convenience-command sources and scrollbar presentation source publicly inspectable. Synthetic fixtures and source-level checks travel with the code.

It is a preview of interfaces and composition integration, not an installable browser-extension release. The repository preview version is also separate from the scrollbar extension source version. No binary assets or registry packages are published by this event.

That boundary keeps the first public step useful and honest: people can study the source and contracts, while native installation and effective browser behavior still require their own integration and qualification.
