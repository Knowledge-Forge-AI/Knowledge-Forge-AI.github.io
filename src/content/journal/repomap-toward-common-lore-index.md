We are working toward the name **Common Lore Index (CLOE)** for the project currently published as RepoMap. The rebrand is in progress. The repository, Python distribution, imports and command-line names still use their existing RepoMap identities; this announcement does not rename an installed command or claim a new package release.

The underlying idea remains concrete: build a deterministic knowledge graph of how a repository works, with facts linked back to source evidence. A useful map follows entry points, imports, scripts, generated artifacts, tests and the configuration that connects them, including paths across language boundaries.

DINAS was the original inspiration. Maintaining a modular workstation made the cost of implicit relationships visible; RepoMap turned that need into reusable repository-analysis machinery. Common Lore Index names the broader direction without discarding that origin.

The public project is still working through pre-v0.1.0 product gates. Its roadmap distinguishes Local, Server Engine and Cloud surfaces; a roadmap target is not proof that every surface is already available. Follow the current source and project documentation for the actual supported setup.
