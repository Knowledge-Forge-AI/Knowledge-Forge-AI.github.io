Stellar Burst 0.4.0 and Nebular Fusion 0.1.0 establish an engine-and-workbench pairing. The core provides brand-system and design-evidence capabilities; the Tauri desktop shell provides a place to review and manage those artifacts locally.

The first Nebular application targets Apple Silicon and consumes authenticated Burst input and a verified Node runtime. The Burst 0.4.0 release distinguishes the source-composition archive from the npm distribution package, because similar-looking archive names are not interchangeable artifacts.

This is macOS developer distribution, not a claim of notarized consumer installation or universal platform support. The workbench adds a visual surface while keeping its engine inputs and package identities inspectable.
