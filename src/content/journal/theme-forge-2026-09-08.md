Stellar Loom 0.1.0 introduces a deterministic Starlight theme compiler, library and CLI. Theme specifications become CSS, descriptors and independently consumable theme packages, with briefs, candidates and reviews supporting human-agent exchange.

Terminal Nova 0.1.0 is a concrete output of that pipeline: the Forge Console design as a standalone Starlight plugin. Consumers do not need the private development checkout or Loom at runtime. Nebular 0.2.0 brings Theme Lab and portable theme-review workflows into the Apple Silicon application.

These are related products, not one interchangeable package. The documentation theme is a project dependency; the workbench is an ad-hoc-signed, unnotarized macOS developer app. Each release keeps its own installation and compatibility boundary.
