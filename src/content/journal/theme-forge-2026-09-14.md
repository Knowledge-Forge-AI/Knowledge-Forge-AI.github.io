Burst 0.5.0 adds a versioned Vector Scene compiler, deterministic SVG output, bounded import and accessibility metadata. Loom 0.2.0 introduces the five-layer Theme v2 compiler, semantic catalog identity and local recompilation of exchanged candidates.

Terminal Nova 0.2.0 adopts the catalog component architecture with orange and cyan accents, while Nebular 0.3.0 provides Brand/System, Vector/Graphics and Starlight Theme work areas using exact Burst and Loom inputs.

The release records preserve important limits. The Burst formula is SVG-only, the Nebular app is macOS ARM64 developer distribution, and no Linux app or notarization is claimed. The Terminal Nova consumer also records an unresolved build-tool exposure; its release should not be described as universally vulnerability-free.
