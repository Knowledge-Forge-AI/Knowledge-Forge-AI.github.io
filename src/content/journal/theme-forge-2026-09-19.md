Solar Sail 0.1.0 extends Theme Forge into Tailwind CSS v4 and shadcn/ui. It provides a deterministic theme compiler, library and CLI, giving another target a concrete translation of declarative visual intent.

Loom 0.3.0 adds reading-layout presets, distribution-safe TypeScript emission, Expressive Code styling and book-chrome navigation. Nebular 0.4.0 repairs its optional Scene resource contract and sidecar timeout semantics; Terminal Nova 0.3.0 supplies the source/provenance reference for its npm theme package.

The workbench gains an npm launcher for macOS Apple Silicon, while Homebrew Cask and Linux app distribution remain outside that release's claims. Terminal Nova is an imported documentation theme, not a standalone application or a Homebrew package.
