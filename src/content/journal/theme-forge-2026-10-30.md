Starlight Theme Terminal Nova 0.4.0 regenerates its Forge Console theme with Loom 0.5.0 and requalifies its canonical graphics with Burst 0.7.0. Its book-chrome layout, accents and consumer-override behavior remain part of the documentation theme.

CTTN 0.1.0 is the first stable Terminal Nova package for Tailwind CSS v4 and shadcn/ui. It provides light/dark tokens, cyan actions, amber accents and status labels and symbols, with compiled JavaScript and declarations and no added runtime dependencies.

The two packages share visual intent but have different integration contracts. STTN plugs into Astro/Starlight; CTTN targets a Tailwind/shadcn project. Browser, visual and assistive-technology acceptance remain distinct from deterministic theme output.
