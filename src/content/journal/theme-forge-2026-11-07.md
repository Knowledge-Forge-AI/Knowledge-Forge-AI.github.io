Terminal Nova, Nebular, Developer, Graphic Designer, Anime and Gamer become six coordinated families, each with light and dark appearances. STTN 0.5.0 carries their Starlight styles; CTTN 0.2.0 exposes the shared catalog and generated CSS for Tailwind/shadcn consumers.

Each GitHub release attaches a frozen, source-matching npm-format tarball, preserved without a rebuild during publication. CTTN qualification spans Apple Silicon and both Linux architectures, while STTN verifies its installed-package demonstration and existing theme surface.

The release-day GitHub notes distinguish the available GitHub artifacts from still-pending npm registry publication and separately qualified demonstration sites. The visual family is shared; package identity, registry publication and website deployment remain separate events.
